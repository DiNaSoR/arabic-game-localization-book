Put the Thmanyah font files here (any of: Thmanyah Serif Display, Serif Text, Sans; .otf/.ttf/.woff2).
Download them from https://font.thmanyah.com/ - the licence does not allow redistributing them,
so everything in this folder except this note is ignored by git.
The cover picks them up automatically on the next run of scripts/build_pdf.py.

A font file placed in the cover/ sub-folder is used for the cover lettering only (front, back, spine).
Milan Display Black (Omar Hassan) is marked "Free for personal use only": a book that is sold needs a commercial licence.
