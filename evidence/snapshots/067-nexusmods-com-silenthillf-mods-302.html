Dialogues, Notes and Menus are fully localised into Arabic for Silent Hill f

Localised by Majood7 aka Sharky

Install:

1. Auto use Vortex just download and install the Mod
or
2. Manual Unzip the .zip file from the downloads

Copy the folder into the "Silent Hill f" Game folder

or move manually "Majood7_AR_99_P" file into the "SILENT HILL f\SHf\Content\Paks\~mods" folder
