Install Guide:
1. Download the file
2. Unzip the file
3. Copy the SHf folder and paste it into the root folder of the game:  "Steam\steamapps\common\SILENT HILL f\"
(Right-click on the game in the Steam library -> Manage -> Browse local files)
4. the mod will override the English language

to remove simply delete the "x5_Arabic_P.pak" from "Steam\steamapps\common\SILENT HILL f\SHf\Content\Paks"

working as of game version v.1.1.378720
